Methodology & Pipeline

How this analysis was built — from raw public data to interactive dashboard.

01 · Ingestion
Data sources & collection
→ VCH Inspection Portal (SPA/REST API)
→ Annual Closure PDFs (2016–2026)
→ Tools: requests · pdfplumber · Selenium
→ Polite scraping: 1.5s delay, retries, caching
02 · Pipeline
Cleaning & transformation
→ Date normalisation & deduplication
→ Violation category classification (regex)
→ Repeat offender detection (join logic)
→ Composite risk score engineering
→ Tools: pandas · numpy
03 · Visualisation
Dashboard & output
→ Interactive dashboard: Chart.js + Vanilla JS
→ Storage layer: Supabase (PostgreSQL)
→ Outputs: CSV · Jupyter notebook · HTML
→ Zero dependencies: single HTML file
